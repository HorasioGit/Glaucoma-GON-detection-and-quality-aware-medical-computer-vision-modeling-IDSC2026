Dataset used in this project:

Hillel Yaffe Glaucoma Dataset (HYGD)
Source: PhysioNet

This dataset contains retinal fundus images with gold-standard annotations
for Glaucomatous Optic Neuropathy (GON), including image quality scores.

Due to licensing restrictions, the dataset is not included in this repository.

You can download the dataset from:
https://physionet.org/content/hillel-yaffe-glaucoma-dataset/1.0.0/
